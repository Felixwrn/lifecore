WRN LifeCore Docs

LifeCore 2.1 for Minecraft 26.3 and Java 25, with WRN API.

Installation

  1. Build lifeplugin-2.1.0.jar with Java 25 and install the current WRN-API.
  2. Put both files into your plugins folder
  3. Restart your server

Commands

/livesgui
/langgui
/modegui
/mode create my_mode
/mode ai my_mode <description>
/market
/challenge
/lifecore update check

LifeCore 2.1 Features

  • Reworked pooled MySQL system and asynchronous player profiles
  • AI Mode Builder: text to validated game-mode preview
  • GUI Mode Builder without AI
  • Configurable HTTPS online features
  • Online Marketplace: verified modes and packs
  • Online Challenges with persistent progress and XP rewards
  • Verified automatic updates, staged for server restart

The AI builder requires an API key. MySQL and automatic downloads are configured by the server operator. See the repository README for commands, migration, online catalogue formats and release configuration.
